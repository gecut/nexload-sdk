## Plugin endpoint

`payloadFieldsPlugin({ slugGenerators, generateSlugAccess })` adds `POST /payload-fields/generate-slug`.

- Authentication is required before the endpoint evaluates custom access.
- A registered generator receives source text and the Payload request on the server.
- The response is `{ slug }` or `{ error: { code, message } }`.
- The final generated value is normalized with `formatSlug`.

<Aside type="caution" title="Do not override package-owned Admin fields">
Consumer overrides may extend supported field options, hooks, metadata, and slots. They must not replace the semantic field type, required component path, or protected name contract.
</Aside>
