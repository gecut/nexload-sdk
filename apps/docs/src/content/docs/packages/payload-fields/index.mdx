Payload Fields owns both the server field definition and the matching Admin component contract. It is designed for Payload CMS applications that need consistent Unicode slugs, Jalali date experiences, and safe money persistence.

<Aside type="caution" title="The database contract is intentional">
Money values in REST, GraphQL, Local API, hooks, validation, and persistence are minor-unit integers. Only the Admin input accepts major-unit text.
</Aside>
