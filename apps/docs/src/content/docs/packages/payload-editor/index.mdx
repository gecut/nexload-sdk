`@nexload-sdk/payload-editor` provides one explicit server-side configuration seam. It owns semantic features, preset contracts, validation, deterministic resolution, and translation to official Payload features.

It does not own rich-text fields, frontend rendering, Blocks schemas, AI actions, themes, or Payload feature dependency sorting.
