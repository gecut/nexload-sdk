---
title: Native Payload extensions
description: Append project-owned Payload Lexical features through the controlled native seam.
---

```ts
import { BlocksFeature } from "@payloadcms/richtext-lexical";
import { createEditor } from "@nexload-sdk/payload-editor";

export const editor = createEditor({
  preset: "article",
  extendFeatures: [BlocksFeature({ blocks: [Callout, Gallery] })],
});
```

Native providers keep their input order and append after managed features. Missing keys and managed/native or native/native duplicate keys throw before Payload's last-wins behavior can hide the collision.

To replace a managed feature, disable it in `features`, then append the native replacement. Payload remains responsible for dependency and priority sorting during sanitization.

Code blocks use Payload's `BlocksFeature` plus the project-owned Blocks schema. AI and themes have no stable package interface.
