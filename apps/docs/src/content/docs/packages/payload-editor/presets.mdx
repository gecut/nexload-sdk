---
title: Editor presets
description: Select or define explicit versioned editor feature contracts.
---

Built-in names describe authoring tasks: `compact`, `standard`, `structured-content`, `article`, and `product-description`. There is no hidden default.

- `compact`: paragraph, bold, italic, link, inline toolbar.
- `standard`: compact formatting plus underline, lists, blockquote, and fixed toolbar.
- `structured-content`: headings `h2`–`h4`, extended formatting, lists, divider, upload, and both toolbars.
- `article`: structured content with `h5`, inline code, and relationship.
- `product-description`: headings `h2`–`h3`, core formatting, lists, upload, and both toolbars.

Relational features in presets use `maxDepth: 1`.

```ts
import { createEditor, defineEditorPreset } from "@nexload-sdk/payload-editor";

const landing = defineEditorPreset({
  features: { paragraph: true, heading: { sizes: ["h2"] }, bold: true },
});

export const editor = createEditor({ preset: landing });
```

`defineEditorPreset` validates and snapshots input. Changing an existing built-in preset contract requires a major release.
