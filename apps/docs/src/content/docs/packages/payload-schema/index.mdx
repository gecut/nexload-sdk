`@nexload-sdk/payload-schema` owns intrinsic field validation and normalization. One entity definition compiles fresh Payload fields and exposes the same canonical Zod schemas for application contracts.

It does not create collections, infer CRUD DTOs, model populated relationships, own authorization, or replace Payload-generated persistence types.
