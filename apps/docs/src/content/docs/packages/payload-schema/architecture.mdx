---
title: Payload Schema architecture
description: Ownership rules, private definition state, compilation, and lifecycle behavior.
---

Factories create immutable public definitions backed by private symbol state. `defineEntity` validates and normalizes that state into a closure-owned IR; neither the IR nor compiler is exported.

```text
field factory → immutable definition → defineEntity
  ├─ payload facade → fresh Payload field configs
  ├─ schema context → canonical Zod contracts
  └─ inspect → safe deterministic metadata
```

Canonical schemas own intrinsic type checks, constraints, and same-type normalization. Payload owns required-field presence, persistence, collection lifecycle, access, drafts, localization, and populated documents. Application schemas own cross-field and use-case rules.

Each schema-capable compiled field receives one server-side `beforeValidate` adapter. Consumer `beforeValidate` hooks run first; the canonical adapter runs last and returns the parsed value. Group and array parents validate only container shape and row limits because Payload traverses children separately.

Every `payload.all()`, `payload.pick()`, and `payload.field()` call deep-clones plain containers by descriptor. Functions, editors, components, regular expressions, maps, sets, and class instances remain opaque references; getters are not executed while cloning.
