Use `defineHealthCheck` for a status-bearing probe and `defineMetricCollector` for monitoring-only collection.

```ts
import { defineHealthCheck } from "@nexload-sdk/healthcheck";

export const licenseCheck = defineHealthCheck({
  name: "license",
  scopes: ["readiness", "diagnostics"],
  critical: true,
  timeoutMs: 1_000,
  async run(ctx) {
    const valid = await verifyLicense({ signal: ctx.signal });

    return {
      status: valid ? "ok" : "unhealthy",
      metrics: { valid },
      error: valid ? undefined : {
        code: "LICENSE_INVALID",
        message: "License is not valid.",
      },
    };
  },
});
```

## Custom check rules

- Honour `ctx.signal`; timeout is cooperative and ignored cancellation can leak or overlap work during retries.
- Use stable machine-readable error codes.
- Return raw numbers, booleans, strings, or `null` as metrics.
- Keep high-cardinality or sensitive values out of metrics, labels, details, resources, and errors. Profiles are context hints, not automatic response filters.

<Aside type="note" title="Thrown errors are normalized">
The manager converts thrown errors, timeouts, and aborts into check results. Let unexpected failures be unexpected; do not throw as a normal status transport.
</Aside>
