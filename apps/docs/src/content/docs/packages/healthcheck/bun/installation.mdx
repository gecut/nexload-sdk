---
title: Install Healthcheck Bun
description: Install the Bun runtime integration and core.
sidebar: { order: 2 }
package: healthcheck-bun
topic: installation
---

```bash
bun add @nexload-sdk/healthcheck @nexload-sdk/healthcheck-bun
```

Use the package manager already used by the project; the package names do not
change with pnpm, npm, or Yarn.

The package depends on core and publishes ESM, CommonJS, and declarations. Run it under Bun; it is not an HTTP framework adapter.
