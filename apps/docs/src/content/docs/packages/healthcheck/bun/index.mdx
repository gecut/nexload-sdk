`@nexload-sdk/healthcheck-bun` connects core to Bun. It reports Bun identity and process memory and can observe pending requests and WebSockets from a `Bun.serve()` server.

It does not create health URLs or export metrics to a monitoring backend. Start with [Installation](./installation/) and [Quick start](./quick-start/).
