---
title: Install Healthcheck OpenTelemetry
description: Install OpenTelemetry transforms with healthcheck core.
sidebar: { order: 2 }
package: healthcheck-otel
topic: installation
---

```bash
pnpm add @nexload-sdk/healthcheck @nexload-sdk/healthcheck-otel
```

Use `npm install`, `yarn add`, or `bun add` with the same package names if the
project does not use pnpm.

Install and configure your chosen OpenTelemetry SDK separately. This package has no OpenTelemetry peer or runtime dependency.
