The core runs checks and metric collectors, normalizes failures into a stable report, and leaves runtime/framework concerns to dedicated packages.

<Aside type="tip" title="Start from the core">
Install the core for orchestration. Add an adapter only for runtime information, route handlers, exporters, or Payload access that your service actually uses.
</Aside>
