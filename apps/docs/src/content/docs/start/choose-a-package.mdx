## Choose by problem

| You need to… | Start with | Add when needed |
| --- | --- | --- |
| expose service probes and reports | `@nexload-sdk/healthcheck` | Node, Bun, Next.js, Payload, Prometheus, or OpenTelemetry adapters |
| ship a Node or container health endpoint | `@nexload-sdk/healthcheck-node` | `@nexload-sdk/healthcheck-next` for App Router routes |
| build Payload fields with Persian-aware UI | `@nexload-sdk/payload-fields` | its generated Admin Import Map subpaths |
| validate environment configuration | `@nexload-sdk/env` | Docs planned |
| use structured logs | `@nexload-sdk/logger` | Docs planned |
| create policy-driven JWTs | `@nexload-sdk/jwt` | Docs planned |
