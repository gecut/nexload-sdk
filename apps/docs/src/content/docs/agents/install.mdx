The repository ships validated, self-contained Skills adhering to the Agent Skills Specification v1.0. The official `skills` CLI discovers the current `skills/**/SKILL.md` files, so the list command is the source of truth instead of a hard-coded count. Each Skill keeps its core workflow in `SKILL.md` (< 400 lines), routes deeper package contracts through `references/`, and commits behavior plus trigger cases under `evals/`.

<Steps>

1. Inspect the available Skills before installing:

   ```bash
   npx skills add gecut/nexload-sdk --list
   ```

2. Install reasoning skills for complex architectural and critical thinking:

   ```bash
   # Install the Cognitive Graph Kernel
   npx skills add gecut/nexload-sdk --skill nexload-reasoning

   # Or install a specific specialist directly (e.g. Investigation for root-cause debugging)
   npx skills add gecut/nexload-sdk --skill nexload-reasoning-investigation
   ```

3. Install foundational engineering standards:

   ```bash
   # Strict TypeScript and boundary narrowing
   npx skills add gecut/nexload-sdk --skill nexload-code

   # Publishable package integrity
   npx skills add gecut/nexload-sdk --skill nexload-package

   # Reviewer-only CTO architectural judgment
   npx skills add gecut/nexload-sdk --skill nexload-cto-review
   ```

4. Install package-specific operational skills:

   ```bash
   # Healthcheck core or route handlers
   npx skills add gecut/nexload-sdk --skill healthcheck-core
   npx skills add gecut/nexload-sdk --skill healthcheck-nextjs-routes

   # Payload CMS fields or operations
   npx skills add gecut/nexload-sdk --skill payload-fields-core
   npx skills add gecut/nexload-sdk --skill payload-operations-core
   ```

5. Update installed Skills when you intentionally want newer guidance:

   ```bash
   npx skills update
   ```

</Steps>

<Aside type="caution" title="Review before broad installation">
  `--all` can install every Skill for every detected agent. Prefer a specific
  Skill or the interactive command unless the repository is intentionally your
  shared agent baseline. Use the <strong>One-Shot Project Adoption Prompt</strong> on the <a href="/nexload-sdk/agents/">Agent Skills overview page</a> to let an agent install only the skills that pay rent.
</Aside>
