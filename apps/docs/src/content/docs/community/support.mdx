Use GitHub Issues as the single public channel for bugs, documentation corrections, and feature requests.

<p><LinkButton href="https://github.com/gecut/nexload-sdk/issues" icon="external">Open an issue</LinkButton></p>

## Report a useful issue

- Name the package and installed version.
- Include the smallest reproduction or the exact documentation page.
- State runtime and framework details when relevant.
- Remove tokens, connection strings, cookies, and production payloads.

<Aside type="tip" title="Documentation corrections">
Use the “Edit this page” link on any page when the correction is local to that document. Source behavior still takes priority over prose when they conflict.
</Aside>
