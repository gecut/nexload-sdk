# Healthcheck Node

Node.js runtime, process, container, TCP, and DNS health integrations.

**Topic:** overview
**Package:** `@nexload-sdk/healthcheck-node` v2.1.0
**Canonical page:** https://gecut.github.io/nexload-sdk/packages/healthcheck/node/
`@nexload-sdk/healthcheck-node` adds Node runtime facts, process metrics, cgroup-aware container resources, and TCP/DNS dependency checks to core.

Use it for probes inside Node services. It does not create HTTP routes; use your framework or `@nexload-sdk/healthcheck-next`.

Start with [Installation](./installation/) and [Quick start](./quick-start/). Container and network details are in [Concepts](./concepts/); all exports are in [API](./api/).
