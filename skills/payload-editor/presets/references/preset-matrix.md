# Preset matrix

- `compact`: paragraph, bold, italic, link depth 1, inline toolbar.
- `standard`: compact plus underline, lists, blockquote, fixed toolbar.
- `structured-content`: headings h2-h4, extended formatting, lists, blockquote, divider, upload depth 1, both toolbars.
- `article`: structured content with h5, inline code, relationship depth 1.
- `product-description`: headings h2-h3, core formatting, lists, upload depth 1, both toolbars.
