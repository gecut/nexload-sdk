# `@nexload-sdk/persian` v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and document `@nexload-sdk/persian` 1.0.0, a zero-dependency Persian/Iranian utility package (digits, text, mobile, identity, bank, money, Jalali date, relative time, provinces, optional Zod schemas), and add it to the `apps/docs` site.

**Architecture:** One package at `packages/persian` with one subpath per module (`./digits`, `./text`, …, `./zod`). Root `.` re-exports every module except `./zod`. Pure functions only; Jalali conversion uses our own implementation of the jalaali-js algorithm; `Intl` is used only to read wall-clock parts in a timezone.

**Tech Stack:** TypeScript 5.9, esbuild via `@nexload-sdk/bundler` (ESM `.mjs` + CJS `.cjs` + `.d.ts`), `node --test`, Zod 4 (optional peer), Astro Starlight docs (`apps/docs`).

**Spec:** `docs/superpowers/specs/2026-11-23-persian-package-design.md` — read it first. Where this plan is more specific, this plan wins.

## Global Constraints

- Package name `@nexload-sdk/persian`; directory `packages/persian`; `package.json` `"version": "0.0.0"`; a Changeset `major` releases `1.0.0`.
- **No runtime `dependencies`.** No import of `payload`, `@payloadcms/*`, `react` or DOM APIs anywhere.
- `zod` only in `src/zod/**`; `peerDependencies.zod = ">=4.1.0 <5.0.0"`, `peerDependenciesMeta.zod.optional = true`, `devDependencies.zod = "4.4.3"`.
- Build: `createBundler(entries, "dist", process.cwd(), { platform: "neutral", target: "es2022" })()` (ESM + CJS). `"sideEffects": false`. `"type": "module"`.
- Every exported function that receives user input accepts `null | undefined` and never throws on bad input, unless the spec says `RangeError`. Invalid input → `null` / `false` / `{ ok: false, reason }`. **Never return invalid input unchanged.**
- Canonical forms: mobile `09XXXXXXXXX`; E.164 `+989XXXXXXXXX`; national code 10 ASCII digits; postal code 10 digits; legal ID 11 digits; landline 11 digits `/^0[1-8]\d{9}$/`; card 16 digits; Sheba `IR` + 24 digits.
- Default timezone `"Asia/Tehran"` (`TEHRAN_TIME_ZONE`). Output must not depend on the process `TZ`.
- Persian grouping separator `٬` (U+066C), Persian decimal separator `٫` (U+066B). Latin: `,` and `.`.
- Never use `console.*` in `src/`. Edit `src/`, never `dist/`.
- Tests: `.mjs` files in `packages/persian/test/`, `node:test` + `node:assert/strict`, importing from `../dist/<module>/index.mjs`. Package `test` script: `pnpm build && node --test test/*.test.mjs`.
- Git: work on `main`, no branches, no push, no publish. The index already holds unrelated staged changes; **commit only your paths** with `git commit -m "<msg>" -- <paths>` and check `git show --stat HEAD`. Never stage or revert other files. Commit footer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- enola: never run `enola baseline pin`. At the end run `enola --generate` then `enola check`; report the exit code. Exit `3` (baseline not comparable) is reported, not fixed.

## Review Focus

1. **Text copied from apps carries invisible marks** (`"‏۰۹۱۲ ۳۴۵ ۶۷۸۹"`, RLM/LRM/NBSP). Normalizers must strip them, not reject the input. Test in Task 3 (mobile) and Task 4 (identity).
2. **Process timezone is not Tehran** (servers run in UTC, CI in other zones). Date output must be identical. Task 7 runs the date tests a second time under `TZ=America/New_York`.
3. **Numbers instead of strings** (`84575948` for national code `0084575948`, `9123456789` for a mobile). Accept `number`, convert with `String()`. Tests in Tasks 3 and 4.
4. **Huge or exotic numeric text** (`"1e21"`, `"۱۲۳۴۵۶۷۸۹۰۱۲۳۴۵۶۷۸۹"`, `"1,2,3"` is fine, `"--5"` is not). `parseNumber` / `parseMoney` return `null`; unsafe integers never become `Money`. Tests in Tasks 1 and 6.
5. **Calendar edges**: Esfand 30 in a non-leap year (`1404/12/30`) is invalid; in a leap year (`1403/12/30`) valid; `endOfJalaliYear` for a leap year ends on 30 Esfand. Tests in Tasks 7 and 8.
